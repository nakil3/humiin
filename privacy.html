Политика конфиденциальности

Приложение «Twitch Clip Uploader». Обновлено 27 августа 2026 года.

1. Общие сведения

«Twitch Clip Uploader» — персональное некоммерческое приложение, которое запускается на личном компьютере владельца. Оно не является публичным сервисом: сторонние пользователи не регистрируются и не используют его.

2. Какие данные обрабатываются

Приложение работает исключительно с данными самого владельца:

  • Токены доступа Google (OAuth). Хранятся только на локальном диске владельца и используются для загрузки видео на его собственный YouTube-канал.
  • Видеозаписи публичных трансляций Twitch и вырезанные из них клипы. Хранятся локально.
  • Сообщения публичного чата трансляции. Используются в момент работы только для подсчёта частоты сообщений — так определяется интересный момент. Тексты сообщений и имена авторов не сохраняются и никуда не передаются.

3. Какие данные НЕ собираются

  • Персональные данные третьих лиц.
  • Платёжная информация.
  • Данные о местоположении.
  • Аналитика и данные для рекламы.

4. Использование данных Google

Приложение запрашивает единственное разрешение — https://www.googleapis.com/auth/youtube.upload. Оно используется строго для одной цели: загрузить подготовленный видеофайл на YouTube-канал владельца приложения.

Приложение не читает, не изменяет и не удаляет существующие видео, плейлисты, комментарии, подписки и данные профиля.

Данные, полученные через Google API, не передаются третьим лицам, не продаются и не используются для рекламы или обучения моделей. Использование и передача данных, полученных через Google API, соответствуют Политике Google API Services User Data, включая требования Limited Use.

5. Хранение и защита

Токены доступа и видеофайлы хранятся локально на компьютере владельца. Серверов, облачных баз данных и внешних хранилищ у приложения нет.

6. Сторонние сервисы

Приложение обращается к следующим API:

  • Twitch API — для получения информации о трансляциях.
  • YouTube Data API — для загрузки клипов.
  • Groq API — для распознавания речи и создания короткой подписи к клипу. Передаётся только фрагмент звуковой дорожки клипа.

7. Отзыв доступа

Владелец может в любой момент отозвать доступ приложения к своему Google-аккаунту на странице myaccount.google.com/permissions. Локальные файлы токенов при этом удаляются вручную.

8. Изменения

Актуальная версия политики всегда доступна по этому адресу. Дата последнего обновления указана в начале страницы.
